# Performance Skill

## Goal

Maintain fast loading times and efficient frontend rendering.

---

# Performance Rules

* Avoid unnecessary dependencies.
* Optimize images and videos.
* Use lazy loading when appropriate.
* Minimize bundle size.

---

# React Performance

* Prevent unnecessary re-renders.
* Avoid expensive operations in render.
* Use dynamic imports for heavy sections.

---

# Asset Optimization

* Compress images whenever possible.
* Avoid oversized assets.
* Prefer modern image formats.

---

# UX Performance

* Prioritize perceived performance.
* Avoid layout shifts.
* Ensure smooth scrolling and animations.
